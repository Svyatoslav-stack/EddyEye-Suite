# EddyEye Suite

**Advanced Tools for Eddy Covariance Data Analytics**

EddyEye Suite unifies Map, Pulse, Hub and ELog into a comprehensive ecosystem that empowers scientists and technicians to track ecosystem health, gain insights from flux data, respond quickly when issues arise, and maintain systematic documentation of field operations.

🌐 **Live Demo**: [svyatoslav-stack.github.io/EddyEye-Suite](https://svyatoslav-stack.github.io/EddyEye-Suite/)

---

## Modules

### 🗺️ EddyEye Map
**For Technicians** | Real-time Updates | Network Overview | Issue Detection

Monitoring and visualization system designed to support researchers and technical teams working with distributed environmental measurement networks. Enables continuous oversight of field stations, providing real-time status information and facilitating rapid identification of operational issues.

- Update Frequency: Every Minute
- Time Window: Real-time
- Data Types: High & Low Frequency

---

### 📡 EddyEye Pulse
**For Scientists & Technicians** | High-frequency Data | Smart Alerts | Rapid Detection

Advanced dashboard for rapid detection of outages, sensor interference, or logger failures through comprehensive high-frequency data monitoring. Provides continuous surveillance of data streams with adaptive site-specific intelligence.

- Update Frequency: Every 30 Minutes
- Time Window: 24 Hours
- Data Types: High-Frequency Streams

---

### 📊 EddyEye Hub
**For Scientists** | Long-term Analysis | EddyPro© Integration | Data Summarization

Comprehensive dashboard for analyzing ecosystem flux dynamics across weekly, monthly, and annual scales with advanced data summarization capabilities. Operates a sophisticated daily processing pipeline with automated flux calculations.

- Update Frequency: Daily Processing
- Time Scales: Weekly, Monthly, Annual
- Data Integration: Multi-frequency & EddyPro©

---

### 📝 EddyEye ELog
**For Research Teams** | Field Documentation | Incident Reports | Team Coordination

Specialized documentation system that supports researchers and engineers in maintaining systematic records of field observations and equipment performance across distributed monitoring networks.

- Update Frequency: Real-time Logging
- Time Scope: Long-term Records
- Documentation Types: Incidents & Maintenance
